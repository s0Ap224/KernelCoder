# Changelog

## 0.1.0

- Initial KernelCoder source release.
- Unified package, CLI, environment variables, and configuration under the KernelCoder name.
- Included local and E2B execution, setup and offline diagnostics, workspace review, and optional MCP tooling.
- Require Python 3.11+ to match the pinned E2B SDK.
- Resolve operating-system temporary-directory aliases before preparing managed MCP jobs on macOS.
